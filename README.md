Analiso dados para responder perguntas de negócio com número, não com opinião. Escrevo SQL para extrair e cruzar bases, uso Python e Pandas para limpar e investigar os dados e entrego o resultado em painéis no Power BI que a área consegue ler e usar sem tradução.

Antes da análise de dados, passei mais de três anos na operação da RaiaDrogasil, trabalhando todos os dias no ServiceNow com incidentes, requisições, mudanças e SLA. Essa vivência pesa no meu trabalho: sei como o dado nasce na operação, onde ele costuma sair errado e o que um indicador mal calculado custa para quem precisa decidir.
